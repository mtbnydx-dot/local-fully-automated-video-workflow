# 短剧剧本写作

你写的是竖屏短剧，不是长剧、小说或电影。观众随时会划走；每一场戏都要争取注意力，每一次冲突都要给情绪回报，每一集结尾都要让人想继续看。

## 何时使用

- 设计整季分集、单集大纲或人物设定。
- 写开场、正文场景、对白、内心独白。
- 设计反转、爽点、结尾钩子。
- 把场次拆成可生成的分镜片段。
- 诊断已有剧本：哪里平、哪里假、哪里没有兑现。

不用于判断题材该不该立项；那是项目决策，不是写作。

## 核心原则

1. **叙事效率优先。** 每一场戏都要改变信息、关系、权力、资源或危险；不改变任何东西的过场删掉。
2. **情绪优先，因果成立。** 观众要的是情绪释放，不是信息完整；但人物动机、知情状态、道具状态和事件因果必须接得上。
3. **从“转”开始。** 人物已经在压力里，不写普通世界和世界观铺垫；前史打散成冲突中的信息。
4. **高密度。** 每隔一小段时间就要有新的张力、信息或选择；不要连续两场同样强度的冲突，要有起伏。
5. **极致人设。** 欲望要强，处境要极端，选择要有代价；人设靠行为和对白建立，不靠标签。
6. **视觉化。** 写能被看见、听见的动作和物件；少写抽象心理，少用旁白解释。
7. **每集有承诺。** 开场给钩子，中段升级，结尾留下未完成的事件；结局集收束全剧承诺。
8. **类型承诺要兑现。** 明确这一部、这一集给观众的主要爽点，并在结尾兑现；不要挂类型标签却不给对应的情绪回报。
9. **明确情绪代偿。** 观众看短剧是为了被压抑的得到释放、被轻视的得到证明、孤独的得到陪伴；先明确这一集补偿的是什么情绪，再设计事件。

## 写作流程

1. 读 source、分集规划、editor notes，写一句话 logline：谁想要什么，谁挡着，失败会怎样。
2. 先定这一集的大转折、开场钩子和结尾钩子。
3. 列转折链：起点 → 挑衅/发现 → 反击/选择 → 结果 → 新问题。每一环都要改变局面。
4. 写场景。每场至少一个变化；每场至少一个视觉锚点。
5. 自检，改最弱的场景；不要只润色台词。

## 一、先定这一季/这一集要卖什么

- **Logline：** 角色 + 困境 + 不寻常的行动。一句话讲不清，说明故事还没想清。
- **一句话卖点：** 熟悉的类型框架 + 一个新鲜的差异化设定 + 能瞬间形成画面的处境。
- **本集大变化：** 这一集结束时，什么和开始时不一样？关系、权力、信息、资源、危险，至少变一个。
- **本集名场面：** 观众看完会记住哪一个画面或哪一句台词？先把它设计出来。
- **类型承诺：** 这一集主要给哪一种爽感？复仇、逆袭、甜宠、降维、悬疑、亲情，选 1-2 个，不要全上。
- **标题/集名：** 优先具体处境、反差和核心冲突；少用抽象词，不标题党。

## 二、结构：从“转”开始

- 不按原著章节平均切；按“冲突单元”切。一个冲突单元 = 谁想要什么 + 谁阻挡 + 结果 + 新问题。
- 每集结构：**钩子 → 升级 → 大转折 → 兑现/代价 → 新问题**。
- 第一集从“试炼”切入：人物已经在压力里，而不是准备进入压力。
- 每集至少一次大的预期打破；在此之前，用具体的承诺、假设或靠山把它架起来。
- 除结局集外，每集结尾留钩子；结局集兑现全剧的核心承诺。
- 中段不能平：每场都要改变信息、关系、权力、资源或危险。
- 结局不是“打完收工”：要回答开篇提出的问题，并让人物的选择付出代价或得到回报。

结构压缩参考：

| 原型 | 短剧用法 |
|---|---|
| 三幕式 | 钩子 → 对抗 → 兑现；铺垫极短，尽快进入冲突 |
| 英雄之旅 | 从“试炼”开始，不写普通世界；人物已经在局中 |
| Save the Cat | 把节拍表当密度参考；每集按多个节拍推进，不按电影 15 拍展开 |
| 起承转合 | 从“转”开始；“起”藏在冲突和反应里 |

## 三、开场：前几秒决定观众是否留下

- 第一个动作或第一句话就要有视觉或情绪冲击：羞辱、威胁、反常、反差、危险、发现。
- 四类钩子选一个主钩子：
  - **好奇心：** 抛出反常现象，不解释。
  - **悬念：** 设置定时炸弹，制造紧迫感。
  - **共情：** 让主角处于极端弱势，快速建立同情。
  - **爽感：** 直接亮出优势或预告即将发生的反击。
- 让观众迅速知道：谁想要什么，谁挡着，代价是什么。
- 开场要兑现一个小变化、小反击或新信息；不能只抛问题。
- 如果开场跨多个镜头或段落，用“危机建立 → 身份/能力暗示 → 首次反击”的三段式；如果只有一个短片段，就完成其中一到两拍，剩下的交给正文。
- 不写：旁白解释世界观、人物自我介绍、空镜、无冲突的日常、寒暄。
- 第一句台词要揭示立场、关系或利害；不要从“你好”“好久不见”开始。

## 四、人物：欲望、阻力、策略

- 每个主要人物都要有：
  - 想要什么；
  - 怕失去什么；
  - 面对压力时怎么做；
  - 说话方式；
  - 底线在哪里。
- 主角必须行动。不能全程被动、等待拯救、靠别人替她/他解决问题。
- 反派要有真实的筹码和手段。不要让反派降智来成全主角；主角的胜利要来自具体的行动、证据、选择或代价。
- 人物关系要有变化：信任/怀疑、支配/反抗、亲近/疏远、亏欠/清算。
- 人设靠行为和对白建立，不靠标签。不要写“她很坚强”，写她在压力下做了什么。
- 配角要有功能：施压、提供信息、见证、阻挠、诱惑、制造误会。不要只当背景。
- 人物弧光：这一集/这一季他/她改变了什么？不是“性格变好了”，而是选择、认知或关系发生了变化。
- 受众代入：人物的现实压力要能让目标观众理解；但女频/男频/银发只是入口，具体人物要有自己的欲望和选择，不要写成刻板印象。

## 五、冲突与爽点

- 冲突不是吵架，是两个人想要的东西不能同时成立。
- 每个冲突都要有具体对象、代价和结果；不要抽象地写“她很生气”“气氛很紧张”。
- 冲突来源：信息差、误解、秘密、规则、时间压力、资源争夺、关系背叛、身份差距。
- 爽点要延迟：先压抑，再释放。反派越具体地施压，反击越有快感。
- 选 1-2 个主爽感：
  - **复仇爽：** 先受压，再反击；利用延迟奖赏。
  - **逆袭爽：** 被低估 → 公开证明 → 身份/能力/资源反转。
  - **甜宠爽：** 情感安全 + 资源倾斜 + 关系推进。
  - **降维爽：** 绝对能力/信息优势碾压，但要有代价或限制。
- 反击要用具体的筹码、证据、行动或选择，不要靠“其实她很厉害”一句话。
- 每次升级都要付出代价；不要一路顺风。主角赢得太容易，观众不会爽。
- 每场至少一次注意力再抓取；但不要靠连续大吼、打脸、反转堆密度，节奏要有张有弛。

## 六、反转与钩子

- 反转 = 先让观众形成预期，再用前面的细节打破它。
- 反转前要有铺垫；反转后要改变局面，不能只是“惊一下”。
- 每集结尾的钩子要具体：一个新问题、一个新决定、一个新威胁、一个新信息。
- 钩子要让人想知道“人物下一步怎么做”，不是“欲知后事如何”的空钩子。
- 每集结尾的钩子要和下一集开场接得上；不要靠旁白硬接。
- 结局集要兑现核心承诺；不要为了续集留太多尾巴。

## 七、对白：每个人都在争取什么

- 每句台词都要有目的：试探、施压、逃避、讨好、威胁、掩饰、反击、求救。
- 人物不会直接说出真实想法。用潜台词、回避、反问、打断、沉默。
- 不同人物要有不同的说话方式：句子长短、用词、节奏、攻击性、口头禅。
- 不写“信息播报”式对白。把背景信息藏在冲突、误会、选择里。
- 长台词拆成有来有回的短句；允许停顿、没说完、答非所问。
- 避免 AI 味：
  - 句子过于工整、对仗、排比、四字词堆砌；
  - 每个人说话都一样；
  - 情绪直接宣布，比如“我很伤心”“我恨你”；
  - 像念稿，没有停顿、试探和反应；
  - 对话像在完成清单，逻辑太顺，转折太干净。
- 内心独白只在能提供画面外关键信息或情绪时使用；不要重复画面，不要替观众总结。
- 台词要改变权力关系。不能改变任何东西的台词，删掉。
- 每集至少留一句能被记住的台词；金句来自人物在具体处境里的选择，不是漂亮的空话。
- 自检：把一句台词换给另一个角色说，如果还成立，说明人物声音不够区分。

## 八、视觉化：写能被拍出来的东西

- 用可见的动作、物品、空间、光线、声音表达情绪；不要写抽象心理。
- 每场戏至少一个“视觉锚点”：一个动作、一个道具、一个构图、一个反差。
- 首帧/开场画面要能让观众一眼看懂人物处境和关系。
- 动作要具体：谁对谁做了什么，物品怎么移动，结果是什么。
- 剧本阶段写事件和动作；分镜阶段再写景别、运镜、声音。
- 能用画面解决的，不用旁白；能用动作解决的，不用台词解释。
- 连续性：人物知道什么、物品在谁手里、时间/地点/服装要接得上。
- 分镜片段要有可见变化；不要只写“漂亮的空镜”或“氛围感”。
- 声音：环境声、动作声、对白、配乐各有功能；配乐在情绪转折处进入或停止，不要全程满。

## 九、类型引擎

只启用与项目匹配的类型；不要把类型标签当人物。

| 类型 | 核心承诺 | 必须有的压力 | 常见失败 |
|---|---|---|---|
| 复仇/虐渣 | 公义伸张、情绪宣泄 | 反派有权力，主角有证据/筹码 | 主角一直忍，反派太蠢 |
| 逆袭/打脸 | 被低估 → 公开证明 | 具体的轻视、公开场合、代价 | 靠巧合，没有铺垫 |
| 甜宠 | 情感安全、资源倾斜 | 关系阻力、秘密、身份差 | 只有甜，没有冲突 |
| 悬疑/脑洞 | 规则破解、人性博弈 | 公平线索、假解、真解 | 靠巧合，藏信息 |
| 战神/神医/降维 | 隐藏身份 → 揭露 → 碾压 | 真实威胁、代价、限制 | 一路碾压，没有代价 |
| 萌宝/母爱 | 亲情治愈 | 孩子处境、成人缺陷 | 煽情，工具化孩子 |
| 银发/家庭 | 尊严、孤独、迟到的爱 | 家庭权力、现实压力 | 刻板印象，说教 |
| 系统/升级 | 任务 → 代价 → 奖励 → 新任务 | 两难、失败风险 | 系统只发福利 |
| 宫斗/宅斗 | 权力争夺、微观博弈 | 规则、联盟、背叛 | 只有撕，没有权力逻辑 |
| 重生/穿越 | 信息差、改写命运 | 蝴蝶效应、情感债 | 只靠预知，没有代价 |

爽文模块（按需）：

- **金手指开局：** 第一集就建立优势，但优势要有边界和代价。
- **打脸节奏：** 先让观众看到具体的低估，再给公开、具体的证明。
- **升级流：** 每次升级都要有任务、代价和新问题，不要白送。
- **扮猪吃老虎：** 低调要有理由；揭露要改变关系，而不只是“爽一下”。
- **系统流：** 任务要制造两难，不要只发奖励。

## 十、改编

- 改编不是复述。保留原作的核心人物、核心关系、核心名场面和结局承诺。
- 长篇只取主线、核心爽点和必要支线；不要把全部支线塞进短剧。
- 保留原作的气质、时代和人物语言；不要为了套路改掉内核。
- 如果原作慢热，从第一个强冲突切入；把前史打散成冲突中的信息。
- 如果原作多线，选一条主线；其他线服务主线或删掉。
- 改编要回答两个问题：没看过原作的人能不能看懂？看过原作的人能不能认出这是这个故事？

## 十一、写完后的检查

- [ ] 一句话 logline 清楚吗？谁想要什么、谁挡着、失败会怎样？
- [ ] 开场前几秒有视觉或情绪冲击吗？主钩子是什么？
- [ ] 主角在行动吗？有没有全程被动？
- [ ] 每场戏都改变了什么吗？删掉不改变局面的场。
- [ ] 这一集有一次大的预期打破吗？铺垫够吗？
- [ ] 爽点是否延迟、具体、有代价？
- [ ] 结尾钩子是否具体到“下一步怎么做”？
- [ ] 每个人说话能区分吗？有没有信息播报？
- [ ] 有没有用画面/动作代替解释？
- [ ] 人物知情、道具、时间、服装接得上吗？
- [ ] 类型承诺兑现了吗？
- [ ] 有没有为了爽而让人物降智？
- [ ] 结局集收束核心承诺了吗？
- [ ] 还有没有可以删的过场、重复信息、空台词？

## 十二、阶段用法

| 阶段 | 重点 | 不要 |
|---|---|---|
| 整季规划 | 按冲突单元分集；定人物、每集大转折和结尾钩子；保留主线 | 按章节平均切；写世界观百科；把结局拖到最后 |
| 开场 | 一个主钩子；立即进入冲突；小兑现；具体问题 | 铺垫、自我介绍、空镜、寒暄 |
| 正文 | 从上一个事件继续；每场变化；一次大反转；结尾钩子 | 重启、重复信息、平铺、人物降智 |
| 分场/分镜 | 事件拆成可生成片段；每段可见变化；首帧、动作、声音；台词用事件引用 | 用镜头写剧情；每段只漂亮没变化；重写台词 |
| 评审 | 用检查清单诊断；指出场次、台词、因果问题 | 替作者重写；只给空泛评价 |

## 输出纪律

- 遵守当前阶段的 schema 和字段要求；使用已登记的 ID，不凭空发明人物、地点、道具。
- 剧本阶段写事件、动作、对白；分镜阶段再写景别、运镜、声音。
- 叙事和对白用项目语言；需要 `_en` 的视觉描述用英文，具体、可拍摄。
- 每个事件都要有功能；没有功能的删掉。
- 不确定时，选更具体、更视觉化、更有后果的那个方案。
